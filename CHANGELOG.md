# Changelog

All notable changes to EduSync Myanmar will be documented in this file.

## [3.2.0] - 2024

### Added
- App Settings menu item added to all user role navigation drawers (Admin, Teacher, Parent, Donator, Manager)
- Dynamic version loading using package_info_plus in App Settings screen
- Comprehensive build and release documentation

### Changed
- Updated app version from 2.0.0 to 3.2.0
- Improved version display consistency across all drawers
- Enhanced user experience with easier access to app settings

### Fixed
- Version number now dynamically loaded instead of hardcoded placeholder
- Consistent version display across all user interfaces

## [2.0.0] - 2024

### Added
- Multi-role support (Admin, Manager, Teacher, Staff, Student, Parent, Donator)
- Role-based access control and permissions
- Academic management (classes, subjects, exams, grades)
- Attendance tracking system
- Financial management (fees, donations, income/expenses)
- Timetable management
- Announcement system
- Custom forms functionality
- Analytics dashboard
- Multi-language support (English and Myanmar/Burmese)
- Offline-first architecture with local caching
- Cross-platform support (Android, iOS, Web, Windows, Linux, macOS)

### Technical
- Supabase backend integration
- Drift local database for offline support
- Provider + Riverpod state management
- Go Router for navigation
- Material Design 3 theming

## [1.0.0] - Initial Release

### Added
- Basic school management functionality
- User authentication
- Student and teacher management
- Class organization
